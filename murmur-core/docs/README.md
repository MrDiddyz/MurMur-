# MurMur Core
Production-ready intelligence foundation on Next.js + Supabase + OpenAI.

## Setup
1. Copy `.env.example` to `.env.local`.
2. Install: `npm install`.
3. Run: `npm run dev`.
4. Apply `supabase/schema.sql` to your Supabase project.

## Modules
Archive, Signal Engine, Council Engine, Event System, Dashboard, and memory-ready interfaces.
